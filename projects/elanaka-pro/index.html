استيراد نموذج هندسي

استيراد الخامات: نفضّل GLB مضمّن الصور. لملفات OBJ اختر «اختيار مجلد» وحدد المجلد الذي يحتوي OBJ وMTL وTextures. سوف يفحص البرنامج الروابط بين الصور وأسماء المواد، ويفتح الهندسة حتى لو كانت بعض الخامات ناقصة، مع تقرير واضح بالنواقص. إضاءة V-Ray/Corona وملفات IES/HDRI لا تنتقل تلقائيًا عبر OBJ.

GLB · glTF · COLLADA + صور · OBJ/MTL · STL

للـ glTF/GLB أبقِ المتر وY ما لم تكن تصحح ملفًا معروفًا. وحدات OBJ وSTL تحتاج تأكيدك. SKP وDWG وIFC وSTEP لا تُستورد مباشرة؛ صدّرها أولًا إلى GLB أو OBJ من برنامجها.

رابط المشروع

سيتم فحص اتصال GitHub عند فتح التصدير.

استخدم المعرّف نفسه لتحديث المشروع والحفاظ على رابطه. اختر مشروعًا جديدًا للحصول على رابط مستقل.يحفظ البرنامج الدومين لمرات النشر التالية. يجب توجيه DNS إلى GitHub Pages؛ يُفحص الرابط قبل اعتباره جاهزًا.
وجهة النشرتُحفظ المشاريع داخل وجهة واحدة، ولكل مشروع رابط مستقل. المصادقة تستخدم حساب GitHub المسجل على الجهاز.

القياسات بين نقاط على شبكة العرض، وليست بديلًا عن ملف CAD أو فحص هندسي معتمد. تُقسّم النماذج الكبيرة إلى ملفات نقل مع التحقق من سلامتها، ثم تُجمع في ذاكرة المتصفح لعرضها.
